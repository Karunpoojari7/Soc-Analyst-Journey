# Day 8: Network Intrusion Detection with Suricata

## Overview
A controlled Kali Linux lab covering custom Suricata rules,
packet capture analysis, and alert investigation.

## Learning Objectives
- Understand network intrusion detection.
- Write and validate a custom Suricata rule.
- Capture local HTTP traffic using tcpdump.
- Analyze a PCAP with Suricata.
- Troubleshoot detection rules and document findings.

## Confirmed Result
The custom HTTP rule with SID 1000001, revision 2, generated
an alert for the controlled /training-check HTTP request.

## Safety
This was a local training test, not a real attack investigation.
Raw packet captures are excluded from the public portfolio.
