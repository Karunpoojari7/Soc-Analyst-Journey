# Additional Evidence Request – SOC-2026-026

## Authentication Evidence
- SSH authentication logs.
- Account owner confirmation.
- Source address validation.
- Successful login context.
- Session identifiers.

## Endpoint Evidence
- Process execution records.
- Full command lines.
- Process IDs and parent process IDs.
- Executable hashes.
- Sudo logs and exit statuses.

## Network Evidence
- Firewall connection records.
- DNS query history.
- Network flow metadata.
- Destination reputation.
- Transfer volume and connection duration.
- Available TLS metadata.

## Identity and Account Evidence
- Account configuration before and after activity.
- Account group membership.
- Privilege assignments.
- Account modification audit records.

## Investigation Purpose

Validate whether the observed activity was authorised,
identify the scope of possible impact, and determine whether
containment and incident escalation are required.
