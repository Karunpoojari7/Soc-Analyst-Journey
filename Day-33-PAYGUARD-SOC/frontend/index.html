Cryptographic Forensic Evidence Vault

Append-only audit trail with SHA-256 hash chaining and HMAC manifest signing.

Audit Ledger Immutability Architecture SHA-256 Hash Chained

Every transaction state transition, authentication failure, and analyst override is recorded in an append-only SQLite ledger protected by SQL triggers (trg_audit_no_update, trg_audit_no_delete). Each record hash is chained cryptographically: H_n = SHA256(H_{n-1} || payload_sha256 || decision_reason).

Application Triggers
Enforces append-only rule at ORM and SQL client layer.
Hash Chain Integrity
Detects any disk-level row tampering or re-ordering.
HMAC-SHA256 Manifest
Signs total record count and final ledger hash for court audit.
