# Active Directory Architecture

## Core components
- Forest: Top-level Active Directory structure.
- Domain: Directory and administrative boundary.
- Domain Controller: Provides directory and authentication services.
- OU: Organizes directory objects.
- GPO: Applies configuration and security policies.
- Security groups: Manage permissions and access.
- SPN: Identifies a service instance for Kerberos.

## SOC relevance
Investigate domain relationships, account ownership, group membership,
Domain Controllers and security policy configuration.

## Lab limitation
No live Active Directory domain was queried during this exercise.
