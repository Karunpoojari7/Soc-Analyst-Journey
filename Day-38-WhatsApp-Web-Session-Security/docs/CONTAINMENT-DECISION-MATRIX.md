# Day 38 — Containment Decision Matrix

| Situation | Recommended action |
|---|---|
| Unknown linked device | Verify ownership and revoke if unauthorized |
| Active session on shared computer | Explicitly log out |
| Suspicious messages sent | Preserve evidence and investigate |
| Account impersonation suspected | Warn affected contacts |
| Financial fraud reported | Contact bank and report through official channels |
| Repeated suspicious access | Escalate to incident response team |

All actions require appropriate account-owner or
organizational authorization.
