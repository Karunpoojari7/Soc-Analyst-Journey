# Day 9: Threat Intelligence and IOC Investigation

## Overview
This lab documents a beginner-level threat intelligence investigation
using the VirusTotal web interface.

## Objectives
- Review an IPv4 indicator.
- Interpret VirusTotal detection and contextual information.
- Distinguish detection counts from proof of malicious activity.
- Document findings, limitations, and evidence integrity.

## Tool
- VirusTotal: https://www.virustotal.com/

## Training Indicator
`192.0.2.25` — an IPv4 address reserved for documentation examples.

## Portfolio Contents
- `notes/` — investigation learning notes
- `report/` — investigation report
- `evidence/` — SHA-256 checksum record

## Key Takeaway
Threat intelligence is a source of evidence, not a verdict. Validate
findings with context and corroborating telemetry before drawing
incident conclusions.

## Safety and Scope
This exercise uses a documentation-range IP address. No live attack
or real-world malicious activity is claimed. Do not submit confidential
indicators, private files, credentials, or sensitive data to public
threat-intelligence services.

## Disclaimer
Educational lab for defensive cybersecurity learning.
