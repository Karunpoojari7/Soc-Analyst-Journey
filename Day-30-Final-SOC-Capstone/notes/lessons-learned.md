# Day 30 — Lessons Learned

## Technical learning
- Authentication events provide evidence of account access attempts.
- Correlation helps build investigative timelines.
- Process and network telemetry provide additional context.
- Detection logic must be tested and tuned.
- Severity must consider impact, confidence and asset context.

## Investigation discipline
- An alert is not proof of compromise.
- A time sequence does not prove session attribution.
- Evidence gaps must be documented.
- Findings must distinguish facts from hypotheses.
- Response actions require authorization and coordination.

## Next skills to develop
- Hands-on Splunk Enterprise investigations.
- Windows event log analysis.
- Active Directory investigations.
- EDR investigation and endpoint telemetry.
- Advanced threat hunting.
- Detection engineering and Sigma.
- Incident response documentation and communication.
