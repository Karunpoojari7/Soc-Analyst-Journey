# Day 5 Learning Log

## Topic
Linux Authentication Log Analysis

## Concepts Learned
- Authentication verifies identity; authorization determines permissions.
- Brute force involves trying many passwords against an account.
- Password spraying tries a few passwords across multiple accounts.
- Repeated failed logins followed by a successful login are suspicious but not conclusive.
- Investigations should correlate authentication events with other available evidence.

## Commands Practised
`cat`, `cat -n`, `ls`, `wc`, `grep`, `sort`, `uniq`, `sha256sum`, `sha256sum -c`, `mkdir`, `cp`, `sed`, and `mousepad`.

## Investigation Workflow
Detect → Triage → Investigate → Assess → Respond → Report

## Reflection
The most important lesson is to distinguish an investigative lead from a confirmed finding. Commands must be validated, evidence must be preserved, and conclusions must be supported by available data.

Synthetic training data only. No compromise was established.
