# SOC Analyst Learning Journey

A hands-on cybersecurity portfolio documenting my journey toward becoming a Security Operations Center (SOC) Analyst.

## About This Repository

This repository contains my cybersecurity learning notes, defensive Linux exercises, synthetic log investigations, incident reports, and detection engineering practice.

My focus is on developing practical blue-team skills through structured labs, evidence-based investigations, and clear technical documentation.

## Current Learning Areas

- SOC operations and Level 1 analyst responsibilities
- Linux system inspection and authentication logs
- Networking fundamentals and traffic analysis
- Security event investigation and timeline construction
- Incident reporting and escalation principles
- SIEM searches and detection engineering (planned as training progresses)

## Repository Structure

- `foundations/` — Security concepts and technical notes
- `investigations/` — Incident investigation reports
- `evidence/` — Sanitized and synthetic lab evidence
- `detections/` — Detection rules and test cases
- `scripts/` — Security analysis and automation scripts
- `learning-log/` — Daily learning progress

## Initial Investigation

**Repeated SSH Authentication Failures**

A synthetic authentication-log investigation covering:

- Filtering failed authentication events
- Counting and grouping events by source address
- Reviewing successful authentication records
- Constructing an event timeline
- Writing a preliminary incident report

All sample events are fictional. This exercise does not represent a confirmed real-world attack.

## Approach

My investigation methodology emphasizes:
1. Establishing context
2. Collecting relevant evidence
3. Validating observations
4. Distinguishing facts from assumptions
5. Documenting limitations
6. Recommending appropriate next steps

## Learning Philosophy

I aim to understand not only which commands and tools to use, but also why they are useful, how to interpret their results, and when the available evidence is insufficient.

This portfolio will evolve as I complete additional practical labs and projects.
