# Day 37 — Incident Response Checklist

## Detection
- [ ] Alert reviewed
- [ ] Alert source verified
- [ ] Related events correlated

## Analysis
- [ ] Account ownership checked
- [ ] Privilege changes verified
- [ ] Database activity reviewed
- [ ] API activity reviewed
- [ ] Network activity reviewed
- [ ] Endpoint activity reviewed

## Containment
- [ ] Incident lead notified
- [ ] Containment approved
- [ ] Evidence preserved
- [ ] Actions recorded

## Eradication
- [ ] Unauthorized access identified
- [ ] Credentials or tokens addressed
- [ ] Root cause investigated
- [ ] Security weaknesses corrected

## Recovery
- [ ] System integrity checked
- [ ] Services validated
- [ ] Monitoring enabled
- [ ] Recovery approved

## Closure
- [ ] Incident report completed
- [ ] Lessons learned documented
- [ ] Corrective actions assigned
